# AI Healthcare Recommendation System

## 📌 Project Overview

This project uses Artificial Intelligence and Big Data technologies to
analyze customer feedback in a healthcare environment.

The system uses PySpark for data processing and a pre-trained
DistilBERT transformer model for sentiment analysis.

The goal is to identify customer sentiment, measure sentiment
confidence, and identify negative feedback that may require further
attention.

## 🛠️ Technologies Used

- Python
- PySpark
- Databricks
- Hugging Face Transformers
- DistilBERT
- PyTorch
- Pandas

## 🤖 AI Model

The project uses the pre-trained:

`distilbert-base-uncased-finetuned-sst-2-english`

The model analyzes customer feedback and produces:

- Sentiment classification
- Sentiment confidence score

## 🔄 Project Workflow

Customer Feedback  
↓  
Data Cleaning using PySpark  
↓  
DistilBERT Sentiment Analysis  
↓  
Sentiment + Confidence Score  
↓  
Sentiment Summary  
↓  
Negative Feedback Identification

## 🔍 Key Features

- Data cleaning using PySpark
- Natural Language Processing (NLP)
- Transformer-based sentiment analysis
- Sentiment classification
- Confidence score calculation
- Sentiment percentage analysis
- Identification of negative customer feedback

## 📊 Analysis

The project calculates the distribution of positive and negative
customer feedback and identifies customers associated with negative
feedback.
